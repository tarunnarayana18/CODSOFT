# CODSOFT UI/UX Internship

This repository contains the UI/UX design tasks completed as part of the CodSoft UI/UX Internship Program.

## Task 1 - Mobile App Signup Flow

### Description
Designed a modern and minimal Android mobile app signup flow that provides a smooth onboarding experience for users.

### Screens Included
- Welcome Screen
- Sign Up Screen
- OTP Verification Screen
- Profile Setup Screen
- Success Screen

## Task 2 - Email Template

### Description
Designed a responsive promotional email template with a clean layout and professional appearance.

### Features
- Promotional Banner
- Product Showcase Section
- Call-to-Action Button
- Footer Section
- Responsive Design

## Task 3 - Restaurant Menu

### Description
Designed a modern restaurant menu mobile application UI with categorized food items and intuitive navigation.

### Features
- Home Screen
- Categories Section
- Starters Menu
- Main Course Menu
- Desserts Menu
- Beverages Menu
- Cart & Checkout Screen
